# Privacy Policy for World Government Discord Application

**Last Updated:** September 4, 2026

Welcome to **World Government** ("we", "our", or "the Bot"). We are dedicated to respecting and protecting the privacy of Discord users and communities using our application.

---

## 1. Information We Collect
World Government only processes minimal, non-sensitive data strictly required to deliver community reputation, leaderboards, and star milestone rewards:

- **Discord User IDs & Usernames:** Stored to associate stars, monthly scores, and milestone role awards with the correct Discord account.
- **Guild (Server) IDs & Channel IDs:** Stored to maintain server-specific configurations (such as reward roles, dedicated channels, and cooldown timers).
- **Endorsement Reasons & Timestamps:** Stored when a member endorses another user via `/thank` to generate audit logs and prevent star farming.

We do **NOT** store personal identification, private messages, email addresses, payment information, or IP addresses.

---

## 2. How We Use Information
The collected data is exclusively used to:
1. Track and compute monthly community helper leaderboards.
2. Automatically assign and remove milestone roles based on star thresholds.
3. Generate graphic celebration and leaderboard cards.
4. Detect and prevent artificial star manipulation, spam rings, or trading abuse.

---

## 3. Data Storage and Security
- All bot data is stored in a secure cloud database with restricted access controls.
- Data is partitioned per server and never shared or sold to third parties.

---

## 4. Data Deletion and User Rights
Server administrators can reset server honor statistics at any time using the `/force-reset` command. Users wishing to request data deletion can contact the bot developer directly via Discord (`ID: 1288801215282413644`).
