# 🌟 Jason - Community Stars & Reward Discord Bot

A modern, high-performance **Community Stars & Reward System** Discord bot built in **Node.js 24**, **discord.js v14**, **MongoDB Atlas Cloud**, and **@napi-rs/canvas**.

---

## ✨ Features

- ⭐ **Endorsement System (`/thank`)**: Award +1 ⭐ Community Star to helpful members.
- 🎖️ **Milestone Roles (50, 100, 200, 350, 500 ⭐)**: Automated level-up roles with monthly resets.
- 📊 **Interactive Leaderboards (`/leaderboard`)**: Real-time tabs, pagination, and refresh buttons.
- ⚡ **Auto-Updating Live Leaderboard (`/live-leaderboard`)**: Pinned embed refreshing every 1 minute.
- 🎨 **Visual Graphic Cards (`/post-celebration`)**: Custom Canvas PNG cards with avatars, crowns, and medals.
- ☁️ **MongoDB Atlas Cloud**: 100% persistent data storage.
- 🔒 **Server Whitelist**: Proprietary security protection.

---

## 🛠️ Slash Commands

- `/thank [member] [reason]` — Award a community star
- `/stars [member]` — View star profile & milestone progress
- `/leaderboard` — Interactive server leaderboard
- `/live-leaderboard` — Set up 1-minute live updating leaderboard
- `/post-celebration` — Generate graphic celebration image card
- `/star-roles [set/view/remove]` — Configure milestone roles
- `/star-config [set/view]` — Server announcement settings
- `/help` — Full guide with developer support
- `/ping` — Check latency
